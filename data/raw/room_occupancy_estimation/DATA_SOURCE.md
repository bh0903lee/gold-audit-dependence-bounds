To regenerate the extracted and derived files (from the package root):

    python -I -m zipfile -e data/raw/room_occupancy_estimation/room_occupancy_estimation.zip data/raw/room_occupancy_estimation/extracted
    mkdir -p data/raw/room_occupancy_estimation/derived_60s
    python -I extensions/scripts/resample_occupancy_60s.py data/raw/room_occupancy_estimation/extracted/Occupancy_Estimation.csv data/raw/room_occupancy_estimation/derived_60s/occupancy_60s.csv

The first command is equivalent to `unzip ... -d .../extracted`. The resampling script overwrites an existing output file; its printed `out_sha256` must equal the value in the table.

## Selection conditions (assessed from metadata)
1. Public license: CC BY 4.0 — met.
2. True state recorded independently of the detector: Room_Occupancy_Count was "noted manually" — met.
3. Detector present in the raw data: two binary PIR motion sensors (S6_PIR, S7_PIR); no training; rule Y = S6_PIR OR S7_PIR — met.
4. At least two units: one room (6 m × 4.6 m) recorded on several dates; unit = day — met.

## File structure (schema and timing only)
- 10,129 rows, 19 columns, no missing values. The time zone is not stated; the data were collected at IIIT Hyderabad, India, and `extensions/configs/room_occupancy_manifest.json` uses Asia/Kolkata.
- Seven dates (2017-12-22 to 12-26, 2018-01-10 to 01-11). The UCI page mentions four days, but the file contains seven dates. The primary stratum (weekdays 09:00–17:00) covers four days.
- Readings are nominally 30 s apart (observed gaps 31 s: 6,373; 30 s: 3,614; 61 s: 131; others rare), so they are resampled to an exact 60-second grid by a rule fixed before any interval was computed: within each local clock minute, count = max, S6_PIR = max, S7_PIR = max; minutes without readings are omitted (no interpolation).

## Values seen before the analysis
A structure check printed these whole-file descriptive values: occupancy rate 18.8%, PIR-OR rate 11.8%, false-positive mass P(X=0, Y=1) ≈ 0.0024, false-negative rate P(Y=0 | X=1) ≈ 0.38. The descriptive criterion (f ≤ 0.01) was fixed before these values were seen. No intervals, widths or coverage had been computed.
